# ROGII Private 1位 (≤5.986) 攻略計画

作成: 2026-06-21 / 締切: 2026-08-05（残り約45日）

## 目標と現実

| | 値 |
|---|---|
| Private 1位 | 5.986 / 2位 6.228 / 3位 6.487 |
| 公開手法の天井 | ~7.1–7.4（全て同一lik-PF/GBM系譜のblend+projection） |
| 我々の確定提出(clean) | exp096 提出中（exp090 leak除去版） |
| 鍵となるギャップ | 7.1 → 5.986 = **約1.1ft**。同一情報源のblendでは埋まらない |

**結論**: 1位は「per-well offset の壁」を**公開勢が使っていない角度**で崩した者が取る。
我々の固有武器 = ①exp026 PF×geom（公開stackと誤差相関0.611=部分直交）②Group F幾何外挿
③CUDA GPU解禁（RTX2080S, 系列NN学習可）。**offset壁攻撃に全リソースを投じる**。

## 二本立て戦略

### トラックA「確実な下限押し下げ」（低リスク・LB保険）
- A1: exp096 clean base 確定（提出中）→ 真の下限。
- A2: **PF直交注入(M2)** = clean kernelに exp026 PF×geom を採点時自前計算で第4エンジン化、
  `T=(1-w)*T_clean + w*PF`。借り物OOF禁止（exp073の負転移回避）。期待 7.x → 6.9–7.0。
- A3: lik-PF同等化 = multiscale{3,5,8,12}(exp040)+selector(exp071)統合でPF成分底上げ。

### トラックB「offset壁の質的突破」（高EV・#1の本命）← **自律実験の主軸**
全てローカルleak-safe CV/OOFで回り、LB反映と独立。well-fold厳守・train-only列禁止。

- **B1 exp097 学習型emission PF（GPU, 最優先）**: PF尤度 P(GR|深度) を生ガウシアン→
  小型1D-CNN/Transformer学習スコアへ置換。typewell×lateral局所文脈を見る。emission改善はPF全体を底上げ。
  目標: PF成分 11.0 → 9〜10、blend CV 10.06 → 9以下。
- **B2 exp098 constrained/stochastic DTW**: lateral GR↔typewell GR を制約付き+正則化DTWで対応付けし
  offsetを系列照合で決める。素朴DTW(exp052)は失敗、制約版は未踏。PFと誤差直交なら強力blend素材。
- **B3 exp099 teacher-forced 枝ランカー（GPU）**: multi-hypothesis枝を回帰でなく「選択」する教師ありNN。
  尤度選択MHT(loop#2)は失敗、教師あり枝ランカーは未踏。
- **B4 統合**: B1〜B3 + 既存(PF/geom/trees/nn/attn) を nested-fold NNLSでblend、consistency/parsimonyゲート。

## offset壁の既知事実（再発明防止）

- per-well offset は leak-free信号で予測不能（GR照合/空間/NN/typewell-attn 全paradigm 10回確認、corr≈0.15以下）。
- oracle上限: 4offset/well で CV 4.39 → **構造上 #1圏は到達可能**。問題は「leak-free選択器」が無いこと。
- B1〜B3 は全て「emission/alignment/選択を学習で強化し、leak-free信号からoffsetをより当てる」試み。
